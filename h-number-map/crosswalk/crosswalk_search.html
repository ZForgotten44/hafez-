Cedar Grove H-ID lookup

Type an H-ID (H002620, H0026203, 2620) or a section, lot and grave (M 61 3). Both numbering versions are searched: v1 is the numbering before the Section M rebuild, v2 is the current one (it includes the route-order rebuild of this pass).

Map versions. v1: H000001 to H003185. v2: H000001 to H003218: Section B corrected (the last-column rule removed, plain lots added), Section M's six lots 56, 57, 62, 63, 68, 69 inserted in route order, every number after them moved up. Sections A and C to H are the same in both versions; in B the 19 labels 12, 31, 50 ... moved to their own places and the plain lots 40 ... 360 were added (see the lot list). An old ID can name a different grave in v2, so always say which version a number came from. Burial records are keyed by section, lot and grave, not by H-ID, so a person stays with the same grave when the H-ID changes.
