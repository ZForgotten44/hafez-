Cedar Grove H-ID lookup

Type an H-ID (H002620, H0026203, 2620) or a section, lot and grave (M 61 3). Both numbering versions are searched: v1 is the numbering before the Section M rebuild, v2 is the current one.

Map versions. v1: H000001 to H003185, Section M without lots 56, 57, 62, 63, 68, 69. v2: H000001 to H003191, those six lots inserted in route order, every number after them moved up. Numbers up to H002617 are the same in both. An old ID can name a different grave in v2, so always say which version a number came from. Burial records are keyed by section, lot and grave, not by H-ID, so a person stays with the same grave when the H-ID changes.
