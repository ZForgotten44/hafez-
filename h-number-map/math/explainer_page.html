    03

    Why it confuses

    Three different kinds of problem are mixed together here. They need different fixes, so this section keeps them apart.

    AReading problems

    The number is hard to see or place. Fixed by redrawing the map.

    BSection rules

    Each section counts in its own way. Fixed by numbering everything the same way.

    CData inconsistencies

    Typos, duplicates and conflicts. Fixed only by a person deciding what is right.

    A Reading problems

    • The overall map has no lot numbers at all (section 01, image 1).
    • Where numbers exist they are a few points tall and rotated (section 01, images 2 and 3).
    • Section titles and notes cover lots, and section borders are not drawn.

    B Section-specific rules

    A repeated label is not a duplicate address. "B-19" and "C-19" are different complete addresses. The cost is that a label alone never says where a lot is. Every lookup needs the section too, and each section has its own counting rule.

    04

    The H-number idea

    Number lots by where they fall along one fixed path through the cemetery. The first lot on the path is H000001, the next is H000002, and so on to H003185.

    See the path before the equation

    Illustration · 12 lots
    Question
    How can twelve lots in two sections get one running number?
    Diagram
    Controls
    Working

    Takeaway: a lot's H-number is how many lots the path has already visited, plus one.

    The three rules

    1. The path covers the cemetery in six stretches, called passes, one after another.
    2. Inside a pass it goes level by level, and along each level it visits the lots in a fixed order.
    3. A lot's H-number is the number of lots already visited, plus one.
    Hlot=O+∑j<rWj+k

    O lots in earlier passes. Wj lots on level j of this pass. r the level of this lot. k its place on that level.

    Words used on this page

    • Pass: one of six stretches of the path.
    • Level (also called row): one step of a pass. A level lists lots from one or two sections.
    • Column and place: a lot's position on its level.

    Level, row and column are decoder indexing. They count positions in the decoder's tables. They are not always the compass rows and columns on the ground, and some sections are drawn rotated.

    The six passes on the map

    Select a pass to see which part of the cemetery it covers. The gold runs from light (the first lot) to dark (the last lot). Press Simulate to watch the path fill in, pass by pass.

    N ↑

    Reading a full address

    Hgrave=10×Hlot+g

    The numeric form holds only for lots without an A or B. A double-row lot keeps its letter between the lot number and the grave digit (H001698A3), and the numeric form cannot carry that letter. Lot H000001 has graves H0000011 to H0000019.

    Step 2 · H-lots push labels along

    Actual system
    Question
    In Section A, how do three H-lots per row change which column each label lands in?
    Diagram
    Controls
    Working
    row r = ⌈ n / step ⌉ place q = n − step × (r − 1)
    column c = (N − 2 − q) + [q ≤ t₁] + [q ≤ t₂] + … an H-lot sits one column earlier
    H(A, n) = SWEEP × (r − 1) + NB + c

    Takeaway: every H-lot slipped in before a place shifts all later labels one column. That shift is why an old label cannot be turned into H without knowing where the H-lots sit.

    Section B, where the column rules disagree

    B's reference formulas give column 2 the label 19 + 20(r − 1), and column 3 (the first body column) also gets 19 + 20(r − 1). The body steps by 20 per row and the last column by 19. The decoder lets the later rule overwrite the earlier one.

    Step 3 · Rows of different widths (D and C)

    Actual system
    Question

    H(D, row r, place k) = 836 + Σj<r (WD(j) + WC(j)) + k

    Step 4 · Twins and trios inside a row (C)

    Actual system
    Question

    Diagram
    Controls

    Working
    k(plain lot n) = (top − n) + 1 + 3·[trio row] + #{ twins t : t > n, or t = n with its H-lot first }

    The giant formula

    This is the formula the whole system rests on. Every old section letter and lot label goes in, and one H-number comes out. It reproduces the decoder for every real label.

    The H-number formula
    H(S,ℓ)=Op(S)+∑j<r(Wj1+Wj2)+σS⋅Wr1+κS(ℓ)

    Tap a term to see what it does for the lot below

    3,197real labels where the formula equals the decoder
    3,139distinct H-numbers they land on, out of 3,185 positions
    13old sections, one formula
    6passes along the path
    How the formula was built, in six steps
    1. Count the lots along one path. A lot's number is the lots already visited, plus one.
    2. Cut the path into six passes. Each pass starts after the last one, which gives O.
    3. Inside a pass, walk level by level. The lots on earlier levels add up to Σ.
    4. When two sections share a pass, the second one starts after the first one's level. That is σ · W.
    5. Write each section's old labelling rule as a place on the level. That is κ, and the table below lists it for every section.
    6. Compile everything into one expression and check it against the decoder, label by label.

    Old address to H-number

    H-number to old label

    κ for each section

    κ is the lot's place on its level. Each section turns its old label into a place in its own way.
