# Cedar Grove Cemetery - site

`index.html` is generated by `../pipeline2/build_site.py` from `../pipeline2/site/template.html`. Do not edit it by hand.
It is one self-contained file; `pdf/` holds the PDFs the Export menu offers (they are fetched relative to the page).

Capabilities (when published as a Claude Artifact): `db` with rules `{path:"", read:"view", write:"admin"}` (everyone who can open the page reads
grave records; only people with edit access write them), `user` (to show Edit only to editors), `downloads` (PDF/CSV saves).
Without them the map, search, review list and area navigation still work; records and downloads are unavailable.
See `../README.md` for the record format and import columns.
